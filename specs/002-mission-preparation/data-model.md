# Data Model

## Overview

The app persists data locally using Expo SQLite. The schema is intentionally small and predictable, using English identifiers in code while exposing Portuguese labels in the UI.

The save-and-return refresh does not add or modify persisted entities. The home screen's in-memory list is a view snapshot and must be reloaded from SQLite whenever the home route regains focus after a form save; existing database ordering and entity validation remain unchanged.

## Entities

### Unit

| Field | Type | Constraints | Notes |
|---|---|---|---|
| id | string | required, primary key | UUID or generated local identifier |
| name | string | required, trimmed, non-empty | Alphabetical ordering in UI |
| createdAt | string | required | ISO date-time string |

Relationships:
- one unit has many youngs

### Young

| Field | Type | Constraints | Notes |
|---|---|---|---|
| id | string | required, primary key | UUID or generated local identifier |
| unitId | string | required, foreign key to Unit.id | Each young belongs to exactly one unit |
| name | string | required, trimmed, non-empty | Displayed in the unit list and edit form |
| age | number | required, integer, 16-25 inclusive | Validation must block under 16 and over 25 |
| gender | string | required, enum: 'male' | 'female' also allowed for API/DB semantics |
| createdAt | string | required | ISO date-time string |
| updatedAt | string | required | ISO date-time string |

Relationships:
- many youngs belong to one unit
- one young has many progress entries

### ProgressEntry

| Field | Type | Constraints | Notes |
|---|---|---|---|
| id | string | required, primary key | UUID or generated local identifier |
| youngId | string | required, foreign key to Young.id | Linked to the owning young |
| date | string | required, ISO 8601 datetime | Generated by the repository from the device timestamp at save time; stored as ISO 8601 datetime (UTC or with offset) |
| text | string | required, length <= 1000 chars | Progress narrative |
| createdAt | string | required | ISO date-time string |

Relationships:
- many progress entries belong to one young

## Validation Rules

- Unit name must be trimmed and non-empty before insert or update.
- Young name must be trimmed and non-empty.
- Young age must be an integer between 16 and 25.
- Under 16 -> error: "Não é permitido cadastrar jovem com idade menor que 16 anos"
- Over 25 -> error: "Não é permitido cadastrar jovem com idade maior que 25 anos"
- Progress text must be non-empty and no longer than 1000 characters.
- Progress date is auto-assigned by the repository using the device timestamp at save time; the UI must not provide a date input for progress entries. The repository stores the timestamp as an ISO 8601 datetime for sorting and persistence. When presented in the UI, the timestamp must be formatted as the Brazilian date DD/MM/YYYY (the app may omit time-of-day in lists and show only the date).

## List and Ordering Rules

- Units are sorted alphabetically by `name`.
- Youngs are sorted alphabetically by `name` within a unit.
- Progress entries are sorted by `date` descending, newest first.

## Local SQLite Schema Sketch

```sql
CREATE TABLE units (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  created_at TEXT NOT NULL
);

CREATE TABLE youngs (
  id TEXT PRIMARY KEY,
  unit_id TEXT NOT NULL,
  name TEXT NOT NULL,
  age INTEGER NOT NULL,
  gender TEXT NOT NULL CHECK(gender IN ('male', 'female')),
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  FOREIGN KEY (unit_id) REFERENCES units(id)
);

CREATE TABLE progress_entries (
  id TEXT PRIMARY KEY,
  young_id TEXT NOT NULL,
  date TEXT NOT NULL,
  text TEXT NOT NULL,
  created_at TEXT NOT NULL,
  FOREIGN KEY (young_id) REFERENCES youngs(id)
);
```

## UI-facing Mapping

- `Unit.name` is shown as the section title in the home screen.
- `Young.name` and `Young.age` are shown together in the unit list.
- `ProgressEntry.text` and `ProgressEntry.date` appear in the young detail screen.
- The screen language remains Portuguese, but the persisted identifiers remain English.
