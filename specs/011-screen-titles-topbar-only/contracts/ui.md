# UI Contract: Screen Titles Only in Top Bars

## Screen title placement

| Screen | Top-bar name remains | Duplicate body heading removed |
|---|---|---|
| Home | Unidades | Unidades |
| New unit | Nova unidade | Nova unidade |
| Edit unit | Editar Unidade | Editar Unidade |
| New young person | Novo jovem | Novo jovem |
| Young-person details | Detalhes do jovem | Detalhes do jovem |
| Not found | Página não encontrada | Página não encontrada |

## Preserved behavior

- Each existing screen name remains visible in its top bar, with the current styling and back-navigation behavior.
- Only a body heading that duplicates the screen's top-bar name is removed.
- Form fields, section headings, instructions, messages, action labels, button behavior, and persisted data remain unchanged.
- A screen that has no duplicate body heading remains unchanged.
