# Data Model: Screen Titles Only in Top Bars

## Scope

This feature does not introduce, modify, or persist domain data. It changes only the presentation of existing screen titles.

## Entities and state

- **None**: Units, young people, progress entries, and all associated state remain unchanged.
- **Screen title**: Existing route display text remains owned by the app's navigation presentation; its duplicate body heading is removed. No title values, relationships, or state transitions are added.

## Validation and migration

- No data validation changes are required.
- No database, storage, or data migration is required.
